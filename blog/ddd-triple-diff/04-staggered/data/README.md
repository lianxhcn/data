# 数据说明

本篇的面板由 `code/01_triplediff_demo.R` 调用 triplediff 包内置的 `gen_dgp_mult_periods(size = 5000, dgp_type = 1)` 在内存中生成，没有独立的外部数据文件，因此本目录不存放数据。运行脚本后，生成的长表包含 15,000 行 (5,000 个单位 × 3 个时期) 和 10 列。

## 列含义

| 列名 | 含义 |
|---|---|
| `id` | 单位标识 |
| `state` | 首次处理队列；0 表示从未处理，2 和 3 表示在对应时期开始处理 |
| `partition` | 资格指示；1 表示符合资格，0 表示不符合 |
| `time` | 时期，取值 1、2、3 |
| `y` | 结果变量 |
| `cov1`–`cov4` | 四个协变量 |
| `cluster` | 聚类标识 |

## 真实参数

- ATT(2,2) = 10
- ATT(2,3) = 20
- ATT(3,3) = 25
- 处理前安慰剂格子 (3,2) 的真值为 0，对应事件时间 e = -1

随机种子为 2025。
