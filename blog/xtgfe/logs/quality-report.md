# `xtgfe-blog` 发布包质量报告

## 1. 验收结论

发布包可以脱离原工作目录运行。快速制图和完整估计两个入口均在 StataNow/MP 19.5、`xtgfe` 1.5.5、`reghdfe` 6.13.1 下返回 0。方法、复现、参考文献和发布质量四项审查最终均通过。

## 2. 程序与运行时间

- `code/run-all.do`：重新估计静态与动态 BIC、三类标准误、桥梁回归、500 次及两组 999 次 bootstrap，随后调用制图程序。估计阶段耗时 1993.047 秒。
- `code/build-figures.do`：读取已核验的动态 BIC 缓存，重新生成 5 张图、绘图 CSV、教学模拟分组诊断和 $G=4$ 核验结果。加入最终断言后的运行耗时 118.625 秒。
- 两份程序均只使用 `c(pwd)` 或调用者传入的项目根目录，没有原工作区绝对路径。
- 两份程序均无超过 76 个字符的代码行。

## 3. 主要结果

- 样本为 90 个国家、7 个五年期、630 条观测。
- 静态 BIC 在 $G=10$ 处最小：BIC 0.0358429，SSR 8.378413。
- 动态 BIC 在 $G=10$ 处最小：BIC 0.0339810，SSR 7.749063。
- 动态 $G=10$：`lag_dem=0.2771791`，`lag_income=0.0752583`，模型隐含的长期乘数为 0.1041175。
- 500 次动态 bootstrap 标准误为 0.2298584 和 0.0184811。
- 两组 999 次 bootstrap 中，`lag_dem` 标准误分别为 0.2285508 和 0.2349430。
- $G=4$ 组规模为 33、13、26、18。
- `xtgfe fx` 与 `e(alpha)` 最大差异为 0；手工 $y-x'\widehat\theta$ 组别—年份均值与 `xtgfe fx` 最大差异为 $4.441\times10^{-16}$。
- 教学模拟中，基准 GFE 为 145/155、最佳标签匹配误分 49；去心 GFE 和 `subgroups(2 2)` 均为 150/150、误分 0。程序包含对应断言。

## 6. 已知边界

动态 `lag_dem` 的 bootstrap 标准误仍高于 Bonhomme and Manresa (2015) 补充材料约 0.124 的参考值。更换种子和增加重复次数没有消除差异。正文和 `logs/issues.md` 已明确说明，不筛除极端重复样本，也不把本地结果写成与论文一致。

正文已经嵌入主要代码，但完整复现仍需要数据、缓存、正式入口程序和核验文件，因此提供 GitHub 项目目录，不再另制 ZIP 附件。
