# 方法说明

程序从节点表和边表构造有向加权网络。入度和加权入度分别衡量收到求助的关系数与次数；出度指标衡量发起求助的关系数与次数。

中介中心性同时提供无权版本和距离版本，均在有向网络上计算，采用 NetworkX 默认归一化。`weight` 是联系强度，不能直接作为 NetworkX 最短路径距离。案例使用透明转换 `distance=1/weight`，隐含“求助频次越高，关系距离越短”的单调假设。该转换只服务于本案例，其他关系数据应根据理论决定距离函数。

结构洞约束和有效规模在将双向求助次数求和后的无向网络上计算。NetworkX 对孤立节点返回缺失；导出表将其编码为 0，并用 `is_isolate=1` 标记。孤立节点的 0 不表示实际结构洞位置，排名时必须排除孤立节点。

社群使用双向权重求和后的对称化网络和 Louvain 算法，固定随机种子。两个孤立节点不进入社群识别，导出时记为 `community=0`。算法分区是描述性结果，不能直接解释为现实中的稳定群体。正式网络图只显示 `weight >= 2` 的边，但所有网络统计和节点指标均基于完整网络。
