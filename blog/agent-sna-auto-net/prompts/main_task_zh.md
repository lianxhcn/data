# 主任务提示词

请读取本项目 `data/nodes.csv` 和 `data/edges.csv`，完成一次可复现的社会网络分析。

这是一张博士生求助网络。`source` 表示发起求助者，`target` 表示被求助者，`weight` 表示一个月内的求助次数。因此，该网络是有向加权网络，`weight` 表示联系强度，不是路径距离。

请先检查字段、缺失值、重复关系、自环、无法匹配的节点、非正权重和孤立节点，并将检查结果写入 Markdown 报告。数据检查没有通过时，不要直接开始计算。

检查通过后：

1. 从节点表和边表构建网络，必须保留没有出现在边表中的孤立节点。
2. 计算网络规模、密度、互惠性、弱连通分量和孤立节点数。
3. 计算入度、出度、加权入度、加权出度、中介中心性和结构洞指标。
4. 对使用最短路径的加权指标，不得直接把联系强度当作距离。请同时给出无权版本和基于 `distance=1/weight` 的版本，并解释差异。
5. 在对称化网络上识别社群，并生成适合中文推文的网络图。
6. 节点大小表示加权入度，颜色表示社群，边宽表示求助频次。
7. 导出节点指标 CSV 和 Stata 19 可以读取的 `.dta` 文件。
8. 保存完整代码、环境依赖、数据检查报告、结果说明和输出验证报告。
9. 固定所有随机种子，保证读者重新运行时得到一致结果。
