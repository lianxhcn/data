# FAQ

## 为什么面板概览报错？

先运行 `check_panel_keys`。缺失主键或重复主键会使 `panel_overview` 拒绝计算。
程序不会自动删行；使用者需要决定如何处理。

## 比例的分母是什么？

全部输入行数，包括重复行。空数据比例未定义，以 NaN 返回。

## HTML 构建成功代表代码运行了吗？

不代表。普通代码块只展示文本。项目另行执行 `tools/verify.py`，
运行 pytest、两个案例、文档 Python 块和 doctest，再完整构建 HTML。

## 网页能执行 Python 吗？

这是静态网站，读者需要在本地安装包运行 Python。

## 中文搜索支持如何？

本次 Sphinx 9.0.4 中文搜索脚本出现 ChineseStemmer 未定义错误，
因此配置为英文搜索索引，已验证函数名检索。中文分词搜索未实现/未验收。
