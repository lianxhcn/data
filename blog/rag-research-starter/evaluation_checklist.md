# RAG 核验清单

## 建库前

- [ ] 每份材料都有稳定编号、版本和获取日期。
- [ ] 每个文本片段保留原始文件名、页码、表号或章节位置。
- [ ] 已确认材料可以按预定方式保存、处理或提交给外部服务。
- [ ] 重要材料没有只保留摘要、网页摘录或二手转述。

## 检索测试

- [ ] 为至少 5 个问题准备了人工标注的正确证据位置。
- [ ] 系统的前 3 个候选片段能覆盖正确证据，或已明确记录漏检。
- [ ] 结果中有相似关键词但不回答问题的片段，被标记为误命中。
- [ ] 对材料中没有答案的问题，系统能够返回「材料不足」或低置信提示。

## 回答核验

- [ ] 每个事实性断言都能回到具体来源位置。
- [ ] 回答没有把不同论文、版本、样本或表格中的信息拼接为一个结论。
- [ ] 回答没有超出检索片段作因果、机制或统计推断。
- [ ] 最终用于综述、研究设计或写作的内容，已经人工回看原文、数据与代码。

## 记录错误

优先记录三类错误：`没有找到`、`找到了但排序错误`、`回答超出证据`。先修正材料、切块或问题表达，再增加模型、向量库或 Agent；这样更容易判断改动是否真的有效。
