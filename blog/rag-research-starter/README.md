# RAG 研究起步材料

这组材料配合连享会推文《AI我知道-08：RAG 是什么？》使用。目标不是搭建一个复杂系统，而是让读者用一组可核对的研究材料，完成一次「提问—检索—回看原文—记录误差」的练习。

## 30 分钟起步

1. 在 `sources_template.csv` 中登记 10 篇与当前研究问题最相关的文献，并补全页码、表号或章节位置。
2. 从 `research_questions.md` 选择 5 个固定问题；每个问题先由人工在原文中标出正确证据位置。
3. 运行 `python minimal_retrieval.py`，查看最小检索器返回的候选片段及其来源定位。
4. 按 `evaluation_checklist.md` 对照人工答案，记录「没有找到」「找到了但排错了」「回答超出证据」三类错误。
5. 再根据 `resources.md` 选择适合自身材料规模的工具或框架。

## 文件说明

- `minimal_retrieval.py`：不依赖外部包的可运行检索示例；它只返回候选证据，不生成答案。
- `sources_template.csv`：研究材料登记表。请在本地保存原始 PDF 或网页，并在表中记录版本、获取日期与定位信息。
- `research_questions.md`：适合综述写作与论文阅读的固定问题和提问模板。
- `evaluation_checklist.md`：检索与回答的人工核验清单。
- `resources.md`：可进一步尝试的官方工具、框架与边界说明。

## 使用边界

本目录不含论文 PDF、受限数据库内容、研究数据或任何账号凭据。示例脚本用的是虚构片段，只用于说明可定位检索的最小逻辑。把材料交给任何云端工具前，应自行确认版权、数据使用规则与保密要求；涉及研究结论、变量构造、识别策略和统计推断时，仍须回到原文、数据和代码核验。
