## 2. BM (2015) 的组数结论

不能把论文中的组数简单概括为唯一的“4 组”或“10 组”。二者对应不同用途：

- 论文正文以 $G=4$ 解释四种典型民主化路径，并绘制分组结果。
- 论文附录使用 BIC 在 $G=1,\ldots,15$ 中选择组数，最小值对应 $G=10$。该 BIC 在论文给定的渐近条件下被解释为真实组数的上界。

推文的规范顺序应为：先展示 BIC 选择过程和 $G=10$ 的核心估计，再用 $G=4$ 复现论文的经济含义与路径图。不能把 `groups(4)` 解释为对初学者的简化推荐。

## 3. 关键参考结果

默认 sandwich 标准误的参考值约为 0.0488 和 0.0080；fixed-T 标准误约为 0.0623 和 0.0099。Bootstrap 标准误取决于随机种子和重复次数。

## 4. 实测结果 (2026-08-05)

- StataNow/MP 19.5 和 Stata/MP 17 均完整测试成功，程序返回值均为 0。
- `xtgfe` 版本为 1.5.5 (July 2026)。
- BIC 搜索耗时约 673 秒，最小值在 $G=10$：BIC 为 0.033981，SSR 为 7.749063。
- $G=10$ 时，`lag_dem=0.2772`、`lag_income=0.0753`、长期收入效应为 0.104117。
- sandwich 标准误为 0.0488 和 0.0080；fixed-T 标准误为 0.0623 和 0.0099。
- Bootstrap 使用默认 `bstarts(32)`。固定种子 8273647 下，100、499、999 次重复的 `lag_dem` 标准误分别约为 0.236、0.230、0.229；`lag_income` 分别约为 0.019、0.018、0.018。
- 种子 8273647 下，999 次 bootstrap 耗时 155.44 秒，全部 999 次重复均被保存。替代种子 20260806 的 999 次结果为 `lag_dem` 标准误 0.235、`lag_income` 标准误 0.018，耗时 203.91 秒。`lag_dem` 的逐次系数分布右偏且厚尾，较大的 bootstrap 标准误并未因增加重复次数或更换种子而消失。
- 该 bootstrap 结果高于 BM Table S.XI 的约 0.124，当前原因尚未完全解释；可能涉及组别分类在单位重抽样下不稳定，以及当前 `xtgfe` 实现与原始程序的差异。不得写成与论文 bootstrap 结果一致。
- 两张 $G=4$ 测试图和完整国家清单均已生成。潜在组编号存在标签置换，应根据路径解释组别。

## 5. 本地 Stata 测试清单

- Stata 17 和 Stata 19 是否均能完整运行；
- `which xtgfe` 返回的版本和安装路径；
- BIC 是否选择 $G=10$；
- 关键系数、SSR 和长期效应是否与参考值一致；
- `groups(15) bic refit`、`groups(10) vce(fixedt)` 和 bootstrap 的运行时间；
- 同一随机种子重复运行时，SSR 和分组是否稳定；
- 两幅图能否正常生成，国家列表是否完整；
- 从 GitHub raw URL 直接执行 `.do` 文件和读取 `.dta` 是否成功。

如果不同版本得到不同局部最优，应增加 `randstarts()` 或 `steps()`，并用 `verbose` 检查多个随机起点是否反复到达同一目标函数值。
